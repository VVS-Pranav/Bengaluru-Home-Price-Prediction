# Bengaluru Home Price Prediction

## Project Overview

This project explores machine learning techniques to estimate residential property prices in Bengaluru, India, using property-related features such as location and area.

The project follows a learning-oriented, end-to-end machine learning workflow based on the Codebasics tutorial.

## Objectives

- Understand and clean real-world housing data.
- Perform exploratory data analysis and feature engineering.
- Apply one-hot encoding to categorical features.
- Identify and handle outliers.
- Train and evaluate regression models.
- Explore cross-validation and hyperparameter tuning.

## Technologies Used

- Pandas

- Scikit-learn

## Machine Learning Workflow

1. Load and inspect the housing dataset.
2. Clean missing, inconsistent, and unnecessary values.
3. Perform feature engineering and reduce dimensionality where appropriate.
4. Encode categorical variables, including property locations.
5. Detect and handle outliers.
6. Train regression models.
7. Evaluate model performance using appropriate validation techniques.

## Dataset

The project uses Bengaluru home-price data associated with the Codebasics tutorial.

Refer to the original project for the dataset source, data preparation steps, and implementation details.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open `bangalore_home_prices.ipynb` in Jupyter Notebook or Google Colab.
4. Obtain the dataset from its original source and update the notebook's data path if necessary.
5. Run the notebook cells in order.
